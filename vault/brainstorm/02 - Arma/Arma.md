# Arma - Mod Architecture Knowledge Base

## Overview

Arma is the tool-focused mod of the [[Ars Mundi]] ecosystem.

Name:

Arma

Pronunciation:

in-stru-MEN-tum

Meaning:

Arma comes from the Latin concept of:

- tool
- instrument
- implement
- device used to perform an action

The name represents the idea that tools are extensions of the player.

Before machines exist, before automation exists, and before advanced systems exist, the player interacts with the world through instruments.

Arma represents:

> The mastery of the world through tools.

---

# Role in Ars Mundi

Ars Mundi is divided into different disciplines.

Each mod represents a specific area of mastery.

Arma represents the discipline of tools.

[[Materia]] provides:

- materials
- gems
- alloys
- components

Arma transforms those materials into:

- mining tools
- harvesting tools
- combat tools
- specialized equipment

Arma answers:

> How does the player directly interact with the world?

---

# Core Philosophy

## Tools Are Extensions of the Player

The philosophy of Arma is that the player should become more capable through better instruments.

A tool is not just a faster version of a vanilla item.

A tool represents a relationship between:

- material
- design
- capability
- player skill

Examples:

A normal pickaxe breaks blocks.

An advanced instrument allows the player to reshape the world faster.

---

# Arma Is Not a Magic Mod

Even though some tools may appear extremely powerful, they are not magical artifacts.

They are not based on:

- spells
- mana
- wizard systems
- fantasy classes

Their abilities come from:

- advanced materials
- technological refinement
- Virtus enhancement

The tool itself is the foundation.

The extraordinary ability is unlocked separately.

---

# Arma Is Not Virtus

A very important design separation exists between Arma and [[Virtus]].

Arma provides:

- tools
- materials compatibility
- default behavior

Virtus provides:

- ability infusion
- unlocking hidden potential
- special effects

Without Virtus:

A hammer is only a pickaxe.

An excavator is only a shovel.

With Virtus:

The hidden capabilities of these tools become available.

---

# Default Tool Philosophy

All Arma tools have two states.

---

# Normal State

This is the default state when the tool is created.

The tool behaves similarly to vanilla Minecraft tools.

Examples:

A hammer:

- behaves like a pickaxe
- mines pickaxe-compatible blocks
- breaks one block at a time

An excavator:

- behaves like a shovel
- mines shovel-compatible blocks
- breaks one block at a time

The player receives a better-designed tool, but not an overpowered ability.

---

# Enhanced State

This state is activated through Virtus.

After infusion:

Tools unlock their special potential.

Examples:

- multi-block mining
- combat abilities
- special interactions

The separation ensures that powerful abilities feel earned.

# Advanced Tools

Arma introduces two specialized tools.

These are enhanced versions of vanilla concepts.

---

# Hammer

## Concept

A hammer is a specialized mining instrument.

It behaves like a pickaxe.

Default behavior:

- mines pickaxe-compatible blocks
- breaks one block at a time

Without Virtus:

The hammer is simply a different form of pickaxe.

---

## Enhanced Hammer

After Virtus infusion:

The hammer unlocks multi-block mining.

Examples:

- breaking multiple connected blocks
- mining larger areas
- advanced excavation patterns

The ability belongs to Virtus.

The hammer only provides the platform.

---

# Excavator

## Concept

An excavator is a specialized terrain tool.

It behaves like a shovel.

Default behavior:

- mines shovel-compatible blocks
- breaks one block at a time

Without Virtus:

The excavator is simply a different form of shovel.

---

## Enhanced Excavator

After Virtus infusion:

The excavator unlocks multi-block terrain removal.

Examples:

- removing large areas of dirt
- clearing terrain faster
- advanced excavation patterns

---

# Tool Materials

Arma provides tool versions for Materia materials.

The purpose is to allow different identities and play styles.

---

# Vanilla Material Tools

Arma extends tool variety with additional specialized tools.

Standard materials:

- wooden
- stone
- iron
- gold
- diamond
- netherite

Hammers and excavators receive additional versions for these materials.

This provides progression similar to vanilla tools while introducing new tool categories.

---

# Gem Tools

Arma provides tool versions using Materia gems.

Gem tools include:

- Carminis tools
- Glaucus tools
- Flavum tools

These materials provide unique identity.

They are not only numerical upgrades.

---

# Exodium Tools

Exodium tools represent exotic End-related equipment.

They represent:

- advanced materials
- unusual properties
- late-game capability

Exodium tools are designed to become among the strongest tools in the ecosystem.

---

# Sword Abilities

Sword abilities are not active by default.

They require Virtus infusion.

The sword provides the material identity.

Virtus activates the ability.

---

# Carminis Sword

Material:

Carminis gemstone.

Concept:

Ruby-like vitality and heat.

Ability:

When used against animals that normally drop meat:

- the animal drops cooked meat instead of raw meat

Purpose:

The sword represents refinement and efficiency.

The player no longer needs to cook the obtained meat.

---

# Glaucus Sword

Material:

Glaucus gemstone.

Concept:

Blue gemstone associated with force and control.

Ability:

When used against mobs or animals:

- pushes the target backward a large distance

Purpose:

Creates battlefield control.

The sword does not simply increase damage.

It changes combat behavior.

---

# Flavum Sword

Material:

Flavum gemstone.

Concept:

Brightness and disruption.

Ability:

When used against mobs or animals:

- applies blindness for a period of time
- prevents effective pursuit of the player

Purpose:

Creates tactical combat advantage.

---

# Copper Sword

Material:

Vanilla copper.

Concept:

A connection between vanilla materials and the Ars Mundi system.

Ability:

When used against mobs or animals:

- applies poison

Additional behavior:

Animals that normally drop meat:

- no longer drop normal meat
- drop rotten flesh instead

Purpose:

Copper represents a corrupted or reactive material behavior.

---

# Exodium Sword

Material:

Exodium.

Concept:

End-related exotic properties.

Ability:

To be defined through Virtus.

The Exodium sword represents the highest level of exotic tool potential.

---

# Final Philosophy

Arma represents the first extension of human capability.

The player begins with hands.

Then creates tools.

Then improves tools.

Then unlocks their hidden potential.

The purpose of Arma is not to replace Minecraft interaction.

It is to make the player feel that their mastery has grown.
