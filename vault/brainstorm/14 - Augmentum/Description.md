# Augmentum

**"Augmentum"** (pronounced *awg-MEN-tum*) — Latin for "augmentation, enhancement, increase — making the already powerful even stronger."

Augmentum doesn't build new systems. It makes the systems you already have perform beyond their limits.

## What's Inside

**Machine Upgrades:**
- Increase Machinum machine efficiency
- Add more capacity to existing processors and internal storage
- Boost output speed without building new machines

**System Improvements:**
- Upgrade energy storage capacity in Potestas reservoirs
- Enhance Fistula transport throughput
- Improve Cista and Peram storage capacity

## How It Fits

Augmentum depends on **Materia**, and the modules it enhances (Machinum, etc.). It belongs to **Ars Mundi**. It's the ecosystem's upgrade layer — improve what exists, don't replace it.

## Why You Want It

Your machines work. Augmentum asks: "But what if they did *more*?" It's the difference between having a system and having the best version of that system.
